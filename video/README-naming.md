# 듣는편람 영상 이름 규칙

- 제목: 기본은 `핵심 주장, 무슨 글인지 (원저자 또는 기관)` — 예: `AI 시대의 매니저의 길, 관리직 종말론에 대한 반론 (Camille Fournier)`. 내용이 돋보이게 시작한다. 저자·기관이 아주 유명할 때만(예: Anthropic) 그 이름을 주어로 시작하고 끝 괄호는 뺀다 — 예: `Anthropic이 git을 떠나 Scion을 만든 이유, 에이전트가 코드를 쓰면 git이 병목이 된다`(2026-10-15 사용자 지정). 저자·기관 이름은 원문 표기 그대로 쓴다(한글 음역 X).
- 회차 ID `YYYY-Www`(ISO 8601 주, 월요일 시작, 기준은 노트 작성일 `date:`, 같은 주 둘째부터 `-2`, `-3`)는 `episodes.tsv`와 썸네일 위 작은 글씨에만 쓴다.
- 폴더/슬러그는 노트 슬러그와 같게(`video/<슬러그>/`), 파일은 `out/<슬러그>.mp4`.
- 업로드는 `uv run video/upload.py <mp4> "<제목>" "<설명>"`(비공개). 올린 뒤 `episodes.tsv`에 한 줄 추가.
- 설명·태그: `video/<슬러그>/youtube.md`에 쓰고 `update_meta.py`로 반영. 원문(영어) 링크와 한국어 번역·정리 노트 링크를 반드시 넣고, `AI 사용 안내:` 줄로 AI 사용(대본 Claude, 나레이션 AI 음성)을 밝힌다. `함께 보기`는 가장 관련 깊은 회차 1개만.
