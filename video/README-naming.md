# 듣는편람 영상 이름 규칙

- 제목: `핵심 주장, 무슨 글인지 (원저자 또는 기관)` — 예: `AI 시대의 매니저의 길, 관리직 종말론에 대한 반론 (카미유 푸르니에)`. 모바일에서 앞부분만 보이므로 주차 같은 관리용 코드는 제목에 넣지 않는다.
- 회차 ID `YYYY-Www`(ISO 8601 주, 월요일 시작, 기준은 노트 작성일 `date:`, 같은 주 둘째부터 `-2`, `-3`)는 `episodes.tsv`와 썸네일 위 작은 글씨에만 쓴다.
- 폴더/슬러그는 노트 슬러그와 같게(`video/<슬러그>/`), 파일은 `out/<슬러그>.mp4`.
- 업로드는 `uv run video/upload.py <mp4> "<제목>" "<설명>"`(비공개). 올린 뒤 `episodes.tsv`에 한 줄 추가.
- 설명·태그: `video/<슬러그>/youtube.md`에 쓰고 `update_meta.py`로 반영. 원문(영어) 링크와 한국어 번역·정리 노트 링크를 반드시 넣고, 타입캐스트·AI 음성 나레이션 언급은 넣지 않는다.
