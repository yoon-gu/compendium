# 듣는편람 영상 이름 규칙

- 제목: `YYYY-Www | 한국어 제목 (원저자 또는 기관)` — 예: `2026-W41 | AI 시대의 매니저의 길, 관리직 종말론에 대한 반론 (카미유 푸르니에)`
- 주차는 ISO 8601 주(월요일 시작), 기준은 compendium 노트 작성일(`date:`). 같은 주에 둘 이상이면 `2026-W41-2`처럼 뒤에 순번.
- 폴더/슬러그는 노트 슬러그와 같게(`video/<슬러그>/`), 파일은 `out/<슬러그>.mp4`.
- 업로드는 `uv run video/upload.py <mp4> "<제목>" "<설명>"`(비공개). 올린 뒤 `episodes.tsv`에 한 줄 추가.
- 설명: 두세 문장 요약, 원문 링크, 정리 노트 링크, "나레이션은 AI 음성입니다."
